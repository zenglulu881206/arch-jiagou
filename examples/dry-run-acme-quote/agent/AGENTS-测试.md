# 通用测试与验收

> **硬门槛**：无「工具与入口树 + 脚本类别表 + 验收维表 + 多帐表 + 脚本存放路径」视为未完成。  
> 清单均为**举例，按链扩展**；详则见 skill `test-acceptance.md`。项目词表/脚本清单正文可进 `docs/项目特化/`，本文件只定规则。

## 技术与工具边界

- 浏览器交互默认：Playwright + 本机 Chrome；**有头**；最大化；动作间隔默认 **0.8** 秒（ERP 默认 **0.8**）
- 统一 launch 入口：`admin/scripts/e2e_launch.py`（脚手架默认 `admin/scripts/e2e_launch.py`）；禁止脚本私造第二套
- 主路径逐步真实交互；禁止前半段 API 造单只测最后一钮
- 目标/验收不清：先澄清再测；正视失败；根因优先；禁止猜修、禁止只打补丁标完成
- 约定端口已占用 = 已启动，禁止再起第二份

## 脚本与产物存放（必须声明）

```text
admin/scripts//          # 常为 admin/scripts/（不进客户包）
|-- e2e_launch.py               # 统一 launch（脚手架自带，必须复用）
|-- closed_loop/                 # 或等价：正反向闭环金样脚本
|   |-- e2e_common.py            # 公共步进/断言（若有）
|   `-- <域>_*.py                # 按链拆分
`-- ...                          # 其它 E2E；新脚本必须复用 launch 与间隔
```

| 产物 | 存放 | 禁止 |
|---|---|---|
| E2E/闭环脚本 | 开发自留地脚本目录（上树） | 打进客户运行包；空手点页面冒充闭环 |
| 本链必测类别登记 | 脚本头注释或 `docs/项目特化/验收脚本清单.md` | 无声明却标完成 |
| 验收汇报 | `log/` | 只写「成功」无前值后值 |

## 总闸

1. **先脚本，后点测**
2. **逐步真实交互** + 完整浏览器权限
3. **测完即清**并复查残留为 0（含自动下推/补单）
4. SQL/API 只读核帐或双闸反例；不得代替主路径办业务

## 脚本类别（举例，按链扩展）

| 类别 | 意图 | 举例 |
|---|---|---|
| 正向 | 主链办结 | 确认后下游出现 |
| 反向 | 回退/取消衔接 | 下游已开始上游应失败 |
| 部分 | 分批/分行/部分量 | 只推一行 |
| 超量 | 超可办量 | 通知量>可通知 |
| 权限 | 越权双闸 | 员越范围；接口仍拒 |
| 漏推/补推 | 自动路径修复 | 补推非主按钮 |
| 并发/幂等 | 重复提交 | 不双写 |
| 其它 | 本链特有 | 须登记；无则 N/A+原因 |

## 验收维度（举例，按改动扩展）

| 维度 | 核什么（举例） |
|---|---|
| 样式统一 | 弹窗三类、列表壳、按钮角色；**PC + 手机窄屏**各走主列表/开抽屉；宽表可横滑、壳唯一 |
| 计算准确 | 与公式说明书源头一致 |
| 数据同步 | 确认后源头数字刷新 |
| 流程衔接 | 上下环互斥；自动/手动下推 |
| 进度事实 | flow.steps 与真实最远环；不串单 |
| 权限同步 | 菜单/按钮/范围双闸 |
| 进行态/行按钮 | 词表与下一环显隐（有则） |
| 回跳 | 办结回来源（有则） |
| 多帐核对 | 见下表 |
| 引导/装配 | 本轮若改了则测 |

## 多帐核对（举例）

| 帐种 | 何时必核（举例） |
|---|---|
| 库存帐占余 + 流水 | 动结存/占用 |
| 上下游流程帐 | 下推/确认/回退 |
| 金额帐 | 改单价数量或过账 |
| 计数帐 | 待办 KPI、列表 total |
| MRP/运算帐 | 有则核；无 N/A |
| 计薪/计件 | 上线后；未上线 N/A |

汇报必须：**前值 → 后值 → 期望差额**（或应不变）；长链逐步核。

## 验收汇报最小段

1. 界面步骤（从基础数据到办结）  
2. 本轮必核帐种 / N/A+原因 + 对照数字  
3. 测完即清：删了什么 + 复查 0 残留
