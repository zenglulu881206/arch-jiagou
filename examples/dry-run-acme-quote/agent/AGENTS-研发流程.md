# 通用研发流程

> **硬门槛**：无「路径选择 + 阶段表 + 访谈默认 + 文档落点 + 完成审查清单」视为未完成。  
> 单个功能字段/验收落 PRD，不写进本文件。目标不清不动手；根因优先。

## 工作路径选择

| 路径 | 何时 | 禁止 |
|---|---|---|
| 只读讨论 | 未要求编码；目标未清 | 提前改业务代码 |
| 单 Agent | 目标清、改动局部、风险有限 | 为拆而拆 |
| 完整多 Agent | 跨模块/高风险/需独立审查与集成验证 | 无任务书开干；同模冒充跨模型 |

代码编辑时声明路径及理由（环境有 `code-editing` skill 则遵循）。多 Agent 角色与模型差异见全局 `~/AGENTS.md`。

## 阶段与产物（必须）

| 阶段 | 做什么 | 产出（举例） | 完成准则 |
|---|---|---|---|
| 1 澄清 | 目标、使用者、约束、假设 | 可验收成功标准 | 标准可检验；否则停止 |
| 2 只读调研 | 查 AGENT/说明书/金样/代码 | 事实与缺口列表 | 能查仓库的不追问用户 |
| 3 方案/PRD | 范围、非目标、流程、落表/公式引用 | PRD 或任务书 | 惯例内事项已按默认定案 |
| 4 实现 | 按脚手架落点改码 | 可审查 diff | 不扩大范围；复用优先 |
| 5 验收 | 按测试 AGENT 脚本与维度 | log 汇报三段 | 根因问题已处理；测完即清 |
| 6 审查 | 对抗性对照规范与需求 | P0/P1/P2 或清单勾选 | 未勾满不宣称完成 |

## 访谈默认（勿再问 · 举例可扩展）

与已上线习惯一致的闸门、回写、幂等下推、草稿物理删除、弹窗三类等 → **直接定案**；只问无先例或与惯例冲突的分叉。写代码前检索复用，禁止同构另造。

## 文档落点（禁止混放）

| 内容 | 入口 |
|---|---|
| 架构与工程硬约束 | `AGENTS.md` / `agent/AGENTS-*` / `admin/AGENTS.md` / `docs/架构图/` |
| 功能字段、流程、验收 | `docs/PRD及测试用例/`（按 PRD 标准分档） |
| 落表百科 / 公式 | 双说明书（活文档，随开发完善） |
| 架构图 / 业务或模块流程图 | `docs/架构图/` 等（活文档） |
| 词表、ROLE 速查、脚本清单 | `docs/项目特化/` |
| 改动记录 | `log/` |

## PRD 分档（摘要）

写/改业务 PRD 前按项目文档模板选 L1/L2/…；不确定按更重档。轻量写成后发现实属重档 → 须补齐硬约束章节。

## 目标与根因（硬）

- 成功标准不清：只澄清，不编码、不出未对齐改动
- 缺陷：先证据与根因，再改；禁猜修、禁补丁债；应急同轮固化到正确入口

## 完成审查清单（举例，可扩展）

- [ ] 范围与非目标仍成立  
- [ ] 落点符合前后端/数据脚手架  
- [ ] 双说明书/金样/特化入口已更新（若触及）  
- [ ] **活文档同轮**：架构图、说明书、业务/模块流程图、引导等凡本轮触及已更新（举例见 skill living-docs；非穷举）  
- [ ] 架构图索引状态诚实；无「玩具图/渲染失败却标通过」  
- [ ] 测试 AGENT 要求的脚本类别与帐种已覆盖或 N/A  
- [ ] 无已知问题被忽略；无靠猜定案
