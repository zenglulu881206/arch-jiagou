## 质量闸门（不过则不得标通过）

下列任一成立 → 该图**不合格**；整套不得写「架构图全部通过」：

1. **残留占位**：文件中仍有未替换的 `{{…}}`，或 Mermaid 节点标签含 `__待填` / `PLACEHOLDER` 未替换。
2. **Mermaid 不可渲染**：围栏内语法错误；节点 ID 含空格；标签误用 `{{`（易解析失败）。以 `scaffold/check-harness.py --render`（mermaid 12.3.0 真实渲染）的结果为准。
3. **与项目脱节**：节点名仍是模板泛称，而仓库已有明确模块/路径/schema（逆向/开发中项目必须贴实际）。
4. **玩具图冒充完成**：仅 2～3 个无信息节点、无边界说明，却标「已出/通过」（测试骨架须标 `测试骨架`）。
5. **与 AGENT 矛盾**：03/04 路径与前后端 AGENT 脚手架不一致；02/08 admin 边界与 AGENT 矛盾。

### 状态枚举（索引必用）

| 状态 | 含义 | 可否计入「通过」 |
|---|---|---|
| `测试骨架` | 仅验证生成器/目录，未按项目精绘 | **否** |
| `骨架` | 绿场刚生成，占位已填但细节未随业务长出来 | **否**（可标 harness 目录齐，不可标图质量通过） |
| `与现状一致` | 已按当前仓库校对 | 该图可勾 |
| `过期` | 代码已变、图未跟 | **否**，须同轮修 |
| `N/A` | 本原型不需要，索引写理由 | 不计入缺图 |

**「目录齐」≠「图质量通过」。** 自检须分两项勾选。

## Mermaid 约束

- 节点 ID：驼峰/下划线，**无空格**；**禁止**在节点标签里写 `{{…}}`（渲染易失败）
- 边标签含特殊字符：用引号 `|"文案"|`
- 不用 `end` 作节点 ID；不用 HTML 实体
- 每文件至少一幅可渲染主图；禁止无图空壳
- 模板占位在 **Mermaid 外**可用 `{{X}}`；写入目标仓前必须全部替换。图内待填用明文中文「待填：…」并标状态 `骨架`

## 生成与演进

1. 复制 `0N-*.md` → 目标 `docs/架构图/`，**替换全部占位**，自检 Mermaid 可预览。
2. 索引写清每图状态（上表枚举）。
3. **开发中**：触及边界/分层/壳/域/权限/部署/主链 → 同轮改对应图（living-docs）。
4. 业务域链变复杂时：09 可拆多文件或加附图，索引登记；讲解用模块流程图另入口亦可，但须同源、勿两套真相。
