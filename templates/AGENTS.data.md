> **举例非穷举**；详则见 `data-protection.md`、`dual-source-docs.md`。对齐架构图 05。

## 技术边界

- 库：`{{DB_STACK}}`（默认 PostgreSQL）
- 库名：`{{DB_NAME}}`（例：`样板 ERP`）
- 业务不进默认 `public`（或等价）
- 改库/落表/计算前：先读本文件 + **grep 说明书再读 §**

## 双事实源（硬）

| 说明书 | 路径 | 回答 |
|---|---|---|
| 数据库说明书 | `docs/数据库说明书.md` | 模式/表/字段/场景落哪张表 |
| 计算公式说明书 | `docs/计算公式说明书.md` | 算法编号与源头函数 |

PRD 只引用场景名/公式编号；禁止平行数据字典或可执行公式副本。未登记公式先与需求方协商。源头同步：其它模块只调源头再展示。

## 模式 / 域划分（必须声明）

| 模式/域 | 用途（举例） |
|---|---|
| `{{SCHEMA_CORE}}` | 主数据、用户角色等 |
| `{{SCHEMA_LIST}}` | 按业务域拆分（sales/purchasing/inventory/…） |
| `schema_migration` 或等价 | 迁移登记 |
| `public` | **空**；不放业务表 |

架构图：`docs/架构图/05-data-domains.md`

## 标识：内部 ID vs 外部 code

| 种类 | 用途 | 规则（举例） |
|---|---|---|
| 库主键 id | ORM/外键 | — |
| 内部数据ID | 迁入对单、稳定关联 | 如 nanoid(24)；新建同事务必写；下推抄上游 |
| 外部业务 code | 给人看的编号 | 与内部 ID 分离，互不顶替 |

禁止靠「数据ID 为空」区分迁入（须用 imported 类标记，若项目需要）。

## 单据落表 / 删除作废 / 字段（类别表）

| 类别 | 硬规则（摘要） |
|---|---|
| 单据生命周期 | 同表 + status；禁草稿/正式拆表 |
| 头行 | 头行分离；写快照；源模块只下推对方草稿 |
| 计算值 | 默认不落业务表；盖章结果除外；改账面唯一过账入口 |
| 删除作废 | 主数据未引用可删；已确认业务禁物理删；草稿可物理删 |
| 字段前缀 | 头 `bill_` / 行 `line_`（若采用）；明细号现算不落库 |
| 业务日 | 业务认业务日字段；禁用 created_at 冒充 |
| 迁移 | 自动迁移=结构+幂等种子；禁自动删业务数据 |
| 历史补数 | 启动 Ensure / 迁入钩子；禁读路径 Ensure；禁迁移 SQL 补客户单 |

## 数据相关资产存放路径

```text
{{BE_ROOT}}/
|-- migrations/                 # 结构迁移（embed）
|-- internal/logic/...          # 源头函数、Ensure、过账入口所在域
|-- internal/dao|model/...      # 表访问与实体
docs/
|-- 数据库说明书.md
|-- 计算公式说明书.md
admin/                          # 清洗/清数脚本（统一预留，不进客户包）
```

| 产物 | 存放 | 禁止 |
|---|---|---|
| 新表/新列说明 | 同轮更新数据库说明书 | 只改代码不改说明书 |
| 新/改算法 | 源头函数 + 同轮更新公式说明书 | PRD/前端平行公式 |
| 离线清洗 | admin/preprocess 或等价 | 改客户旧原始件 |
